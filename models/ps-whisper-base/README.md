# Pashto Whisper base (ONNX, 8-bit) for Jugnu

On-device Pashto speech recognition used by Jugnu (ConceptAI).

- Original model: ihanif/exp_008_base_cv24_vanilla (fine-tuned from openai/whisper-base on Mozilla Common Voice Pashto 24), Apache 2.0. https://huggingface.co/ihanif/exp_008_base_cv24_vanilla
- Converted by ConceptAI to ONNX with 8-bit weights for transformers.js. No retraining.
